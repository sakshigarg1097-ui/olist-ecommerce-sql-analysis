# Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

## Source

The dataset is available on Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains approximately 100,000 orders from 2016 to 2018, along with information on customers, orders, order items, products, sellers, payments, reviews, and product categories.

## Usage

The raw CSV files are not included in this repository.

After downloading the dataset, update the file paths in `03_import_data.sql` before importing the data into MySQL.
